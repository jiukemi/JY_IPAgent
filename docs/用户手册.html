1. 你能用它做什么

按流水线制作本地教育口播视频：

  1. 文案：导入/转写/改写口播稿
  2. 配音：克隆或预设音色生成语音
  3. 口播画面：数字人（推荐 HeyGem）或实拍对口型
  4. 发布：加字幕、封面、BGM 等，导出成片

默认数字人后端为 HeyGem。仅有一张静图时可试 SadTalker（效果通常弱于 HeyGem）。

2. 最低与推荐配置

装机前先对照下表。应用内「设置 → 本机环境」也会按显存提示能否跑各引擎。

项目 最低（能试用） 推荐（完整本地口播）
系统 Windows 10 / 11（64 位） 同左
CPU 近两年主流四核及以上 同左或更好
内存 16 GB 16–32 GB
显卡 NVIDIA 独显，约 6 GB 显存 8 GB+ 显存（如 RTX 3060 / 4060 同级及以上）
磁盘 预留约 40 GB+ 80 GB+（模型 + Docker 镜像）
其它 能安装 Docker Desktop （口播主路径） 同左；Hub 拉不动时用夸克加速包

补充说明：

  • 口播（HeyGem）：建议显存 ≥ 6 GB；低于此值软件会提示，可能无法稳定生成。
  • 本地高品质配音（如 IndexTTS）：常需约 6–8 GB+ 显存；机子偏弱可改用 Piper（CPU）或云端配音。
  • RTX 50 系（5060 / 5070 / 5080 / 5090 等）：口播须用夸克包里的 「RTX50」 镜像，勿下「通用显卡」包。
  • 无 NVIDIA 独显：仍可做文案、部分轻量配音/转写；不要指望本地数字人口播效果。
  • 当前标准安装包（Mini）不含大镜像，需 Docker + 在线拉取或夸克离线包；「免 Docker 完整包」若发布会单独标明。

3. 安装包用户

3.1 安装与首次启动

  1. 运行安装程序（如 九易AI智能体-Setup-*.exe / 仓库发布页提供的 Setup）
  2. 打开应用
  3. 首次启动可能自动准备 Python / FFmpeg（需联网，等待数分钟）
  4. 打开 设置 → 本机环境 · GPU 与模型，按需安装配音、转写等组件

Release / 源码下载页（自动选择 GitHub 或 Gitee）：打开仓库中的 download.html。

3.2 口播引擎（HeyGem）

  1. 打开应用内 口播引擎安装向导（形象页或 设置 → 口播引擎安装向导）
  2. 按向导：检测显卡 → 安装/启动 Docker Desktop（通常需管理员，装完可能重启）→ 下载对应夸克加速包 → 扫描/拖入安装 → 加载镜像并启动
  3. 也可在 设置 → 网盘加速 · 夸克 单独下载与安装；口播分 通用显卡 / RTX50 两包，只下本机推荐的那一个
  4. 有外网且 Docker 能 pull 时，也可跳过夸克，由程序按显卡拉取镜像；第一次约十几 GB，成功一次即可

Docker 验收与磁盘：

  • 不必注册 Docker Hub：个人 / 小团队通常可跳过登录窗。软件验收标准是本机 docker info 成功。
  • 不要用官网图形安装当主路径（默认只能装 C 盘）。请在应用 口播引擎安装向导 里：选磁盘 →「一键安装到所选盘」（会弹一次管理员确认），装到如 D:\Docker\。

软件安装包本身不含大镜像，体积保持较小。当前推荐路径仍是 Docker + 镜像（在线或夸克离线）。

3.3 推荐操作顺序

  1. 完成文案
  2. 完成配音并确认听感
  3. 注册/选择数字人形象（HeyGem 需参考视频；SadTalker 需肖像图）
  4. 生成口播视频
  5. 到发布页加字幕/封面后导出

4. 源码用户

见根目录 README「快速开始」。要点：

  • 复制 config.example.yaml → config.yaml（也可由程序首次启动自动生成）
  • pip install -r requirements.txt
  • 构建 web/ 后执行 start.bat 或 py -3.11 server.py
  • 引擎用 scripts/setup/setup_*.ps1 或应用内安装

5. 引擎怎么选

用途 推荐 备注
数字人口播 HeyGem 需 Docker；参考视频驱动，动作较自然
仅有静图 SadTalker 备选，上限较低
实拍换嘴精修 LatentSync 慢、吃资源
本地配音 IndexTTS 中英混读与克隆较稳
轻量/在线配音 Piper / Edge 能力有限或需联网
转写 FunASR（中文）/ Whisper 按机器与语言选择

未安装的引擎请先在设置页或对应 scripts/setup/setup_*.ps1 装好，再在页面切换。

6. 常见问题

端口被占用

默认尝试 7860，被占用时会自动换邻近端口。看启动窗口提示的实际地址。

首次很慢 / 一直在下载

Python、FFmpeg、模型、Docker 镜像都可能很大。保持联网；可改用国内镜像（如 config.yaml 中的 hf_endpoint）。无外网时用设置里的夸克加速包。

口播页提示引擎未就绪

打开 口播引擎安装向导：确认 Docker 正在运行、已安装对应加速包并完成 load；或重新一键启动。

没有 NVIDIA 显卡 / 显存不够

部分 TTS/转写仍可能可用；HeyGem 与多数本地大模型会明显受限。请对照上文「最低与推荐配置」，或改用云端/轻量引擎。

静图效果差

优先改用 HeyGem + 参考视频；SadTalker 仅作应急。

配置改了不生效

确认改的是运行目录下的 config.yaml，并重启服务。
